# jrichard-web

Source for my portfolio site, hosted on GitHub Pages: **https://joshuarichard116-sudo.github.io/jrichard-web/**

| Path | What it is |
|---|---|
| `index.html` | The whole site: HTML, CSS and JavaScript in one file, with no build step and no outside libraries |
| `labs/talvex-firewall/` | The playable **Talvex Firewall Lab**, a 43-mission firewall and Azure training simulation ([play it](https://joshuarichard116-sudo.github.io/jrichard-web/labs/talvex-firewall/)) |
| `assets/` | Favicon, divider, link-preview image and the resume PDF (phone number removed) |
| `404.html` | Page-not-found screen |
| `sitemap.xml`, `robots.txt` | Help search engines find the pages |

Colors and layout follow the same Spec Sheet style as my project READMEs (see `.github/pizzazz/STYLE.md` in my other repos). The firewall lab is an independent training simulation and is not affiliated with Fortinet.
