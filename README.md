# jrichard-web

Source for my portfolio site, hosted on GitHub Pages: **https://joshuarichard116-sudo.github.io/jrichard-web/**

- `index.html`: the whole site (HTML + CSS, no build step, no external libraries)
- `assets/`: favicon and the amber divider
- `404.html`: not-found page

Colors and layout follow the same Spec Sheet style as my project READMEs (see `.github/pizzazz/STYLE.md` in any of my repos).
